# Lighting image prompts — generate in ChatGPT, save here

Save each finished image into **this folder** (`_incoming/`) with the **exact filename**
given below. Do not paste them into chat — pasted images are not readable from disk.
Once they are here, say so and they get resized, re-encoded and wired into the pages.

## House style

Every prompt already ends with the same style block so the set hangs together:

> Editorial UK interior photography. Photographic and realistic, not a render.
> Warm artificial light. No people, no text, no watermark, no brand names.

Two things worth keeping an eye on when you review each one:

- **No people.** Faces are where AI images give themselves away.
- **UK-looking rooms.** If it comes back looking like a Los Angeles show home,
  add "British home, modest room proportions" and run it again.

say "something like that". They will be labelled as examples, and the site's
